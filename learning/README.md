# Earlier work

This folder contains my original blackjack program (`test.java`) and the manual check programs I wrote while building the project.

The `*Check.java` files use `main()` methods to try out scoring, dealer behavior, betting, payouts, and saving. Some print values to inspect, while others use a small assertion helper.

These files are kept to show how the project developed. They are outside the Maven source folders and aren't included in the application build or run by `mvn test`.
